# ATTRIBUTION — «МЁРТВЫЙ ЭФИР»

## 1. Контент в репозитории

Все файлы проекта созданы специально для этой игры (движок Godot 4.3, MIT):

- **Код GDScript** (все `scripts/*.gd`, генераторы `tools/*.py`,
  сцена `scenes/main.tscn`, иконка `icon.svg`) — написаны для проекта,
  без внешних зависимостей. Лицензия кода — та же, что у проекта целиком
  (см. README).
- **Звук** (`sounds/*.wav`, 24 файла) — синтезированы процедурно скриптом
  `tools/make_sounds.py` (Python, стандартная библиотека `math`/`wave`)
  специально для проекта. Внешние сэмплы не использовались.
  Эквивалентно собственному производству → права принадлежат проекту,
  ограничений на использование нет.
- **Графика** — процедурные StandardMaterial3D + примитивы Godot,
  без внешних текстур/моделей. Placeholder-стиль честно задокументирован
  в docs/ASSETS.md.

## 3. Правила при добавлении внешних ассетов

Каждая строка заполняется ДО коммита ассета:

| Ассет | Источник | Автор | Лицензия | Ссылка |

Допустимые лицензии: **CC0, Public Domain, CC-BY** (для CC-BY — автор
обязательно указывается в титрах игры). Рекомендуемые проверенные
источники: kenney.nl (CC0), polyhaven.com (CC0), ambientcg.com (CC0),
poly.pizza (фильтр CC0), freesound.org (фильтр CC0), opengameart.org
(фильтр CC0/CC-BY). Запрещены: ripped-ассеты, ассеты из Pale Mimic,
паки без указанной лицензии.
