# QA-ЧЕКЛИСТ «МЁРТВЫЙ ЭФИР»

Отметки: ✓ сделано в проекте; ⚠ требует прогона в редакторе (в песочнице
нет бинарника Godot — runtime-проверка невозможна, см. честные ограничения
в README).

## A. Свет (правила 1–12)
- [✓] Каждый источник имеет физический носитель: лампа (L/l), окно (W),
  красный маячок (r), LED-экраны узлов, фонарь, эмиссионные панели станции.
  Источников «в воздухе» нет — все OmniLight/Spotlight созданы внутри
  меши-носителя в level_builder.gd / player.gd.
- [✓] План освещения каждой комнаты: docs/LIGHTING.md, таблицы по 3 этажам.
- [✓] Палитра: тёплый 2700K (#FFB36B-окрестность), люминесцентный 4000K
  (#E8F0E4), холодный 6500K (#9EB8EB), красный — только r/красная дверь.
  Кислотных цветов нет; единственный акцент — зелёный экран узла.
- [⚠] Нет чисто чёрных/белых зон: фон #030405, ambient на каждом этаже
  (0.10–0.18), tonemap FILMIC. Проверка в редакторе: пройти этаж при
  выключенном фонаре — тёмные углы должны читаться фактурой; при
  включённом — блики на металле не должны клипаться в белый.
- [✓] Auto exposure отключён: CameraAttributes не назначен, exposure 1.0
  фиксирован. Проверка на 3 мониторах (тёмный/норма/яркий режим):
  сцена не должна уходить в кашу ни на одном.
- [✓/⚠] Bake: все стационарные лампы BAKE_DYNAMIC (кандидаты LightmapGI);
  динамические тени только у фонаря. Инструкция запекания — LIGHTING.md §Bake.
- [✓] Volumetric fog только плотностью 0.012–0.028 и единым слоем на этаж;
  в маленьких комнатах визуально почти незаметен.
- [⚠] Light leaks: стены толщиной 2 м, дверной проём перекрыт створкой.
  Проверка в редакторе: стоять вплотную к каждой стене комнаты с ярким
  светом за ней — полоса света на полу = leak; снизить range света.
- [⚠] Peter-panning/shimmer фонаря: bias 0.03, normal 1.2; если тень
  дрожит — поднять normal bias до 1.5, не трогать bias выше 0.05.
- [✓] Свет ведёт: лампы над проёмами, окна-ориентиры, красная дверь
  тоннеля, мигающие лампы на поворотах. Проверка: идти по маршруту
  прохождения, не открывая карту — на каждом повороте виден ориентир.
- [✓] ≥2 уровня освещённости в комнате: основной светильник + заполняющий
  (ambient этажа, свет из окна/коридора через проём).
- [✓] Читаемость интерактивов: узлы (N) получили LED-подсветку экрана,
  предохранители лежат под основным светом комнаты, вопросы
  взаимодействия имеет prompt в HUD. Проверка: c 2.3 м каждый
  интерактив виден при выключенном фонаре в своей комнате.

## B. Наполнение карты
- [✓] Все комнаты имеют функцию (docs/MAP.md, таблицы по этажам).
- [✓] Минимальный набор в каждой комнате: арх. деталь (окна/колонны/
  ниши), 2+ функциональных объекта, 3+ следа жизни (мусор, декали,
  манекены, брошенные вещи), 2+ декали grime, 1 звук. маркер (drip/wind/
  hum), 1 интерактив/сюжетная точка. Генерируется в `_furnish_rooms`.
- [✓] Коридоры ≤ 15–20 м между ориентирами (максимальный прямой прогон
  карты ~26 м = 13 клеток, но разбит дверями и лампами l/L через 4–7 клеток).
- [✓] Проходы не заблокированы: коллизия только у крупных объектов;
  мусор — без коллизий.
- [✓] Вертикальность: лестничные переходы 1↔2 и 1↔Б1, техтоннель Б1
  ниже уровня основного пола.
- [✓] Петли/срезы: этаж 1 — кольцо КПП→Холл→Кабинет→Радиоузел со
  возвратом через душевую; Б1 — петля через склад/тоннель.
- [✓] Тупики только с наградой: душевая (бутылка), сфера (записка),
  архив (предохранитель + бутылка), трубная (бутылка).
- [✓] Landmark каждые 20–30 м: мигающая лампа, красная дверь, манекен,
  сломанный лифт, штабель ящиков, антенна.
- [✓] Звуковой дизайн управляемый: базовый дрон каждого этажа + редкие
  one-shot; тишина используется целенаправленно (LISTEN монстра).
- [✓] Монстр честен: спавн/респавн на дальней клетке патруля; слышит
  бег (19 м) и бутылку (26 м); теряет приседающего; jump scare бюджет —
  1 (первая встреча в машзале/тоннеле).

## C. Геймплей / прогресс
- [⚠] Полное прохождение 20–30 мин на нормальной скорости.
- [✓] Прогресс-цепочка: 3×f → F → 4×N → H → тоннель → T → финал (2 концовки).
- [⚠] Смерти корректны: ресет этажа без потери прогресса, fade 0.55 с.
- [⚠] Управление: WASD/мышь/Shift/Ctrl/E/F/Q — зарегистрированы
  в boot.gd; проверить в Input Map, что нет конфликтов с системным Ctrl.
- [⚠] UI: только батарея/задача/промт/записки/выбор финала. Нет маркеров
  и стрелок. Проверить читаемость на 1080p и 1440p (stretch=canvas_items).

## D. Производительность (цель: 60 FPS @ 1080p, GTX 1060)
- [⚠] Замер: Debugger → Profiler в Godot (запуск F5, вкладка Profiler;
  смотреть Frame time, Draw calls, Object count). Ориентиры: draw calls < ~450, треугольники
  < 400k на этаж, VRAM < 1.2 ГБ.
- [✓] Ограничения уже соблюдены кодом: одна плана пола/потолка (2 меша),
  слитые прогонном стен, один источник с тенями (фонарь), MSAA 2×,
  24 коротких WAV (суммарная < 3 МБ), нет post-processing стеков.
- [⚠] Если FPS ниже: выключить MSAA, снизить VolumetricFog до 0,
  перевести лампы с BAKE_DYNAMIC в запечённые LightmapGI (главный
  выигрыш — Light3D станет «бесплатным» после bake).
