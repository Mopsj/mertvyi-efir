# LIGHTING PLAN — «Мёртвый эфир» (вертикальный срез)

## Глобальные параметры (Environment, `scripts/main.gd`)
| Параметр | Значение | Почему |
|---|---|---|
| Background | BG_COLOR `#030405` | окна не должны показывать «дыру» |
| Ambient source/color | COLOR, по этажу: Б1 `#29303D` @0.34; 1 эт. `#212936` @0.38; радиоэт. `#1C2638` @0.34 | «чисто чёрных зон нет» и **играется без фонаря** (P0-фикс ревизии 2); едва читаемая фактура |
| Tonemap | FILMIC, exposure **1.0**, white 6.0 | авто-экспозиция отключена дефолтом (CameraAttributes не подключаются); фикс для 3 мониторов проверяется по QA |
| Fog | exponential, плотность по этажу: 0.028 / 0.012 / 0.016, цвет `#0D1116` | вуаль глубины, не «туман-стена»; без volumetric fog (экономия GPU) |
| Glow | вкл: intensity 0.55, bloom 0.03, HDR-threshold 0.9, blend SOFTLIGHT | слабые источники (аварийные LED, фосфорные метки, экраны) читаются в темноте без «мыла» и без кислотных свечений |

## Свет как проводник (правило 9)
- Каждый проём на этаже подсвечен с одной из сторон (лампы в коридорах на углах поворотов).
- Читаемые ориентиры: красная дверь (Б1) → маяк; лестницы → Label3D «Наверх/Вниз»; узлы → тёплые лампы; серверная → холодные LED.
- Ни одной «стрелки из ламп»: приборные ориентиры сюжетны.

## Как запечь свет для релиза (LightmapGI)
1. В `level_builder.gd` перевести `large_surface`-меши (пол/потолок/стены) в `StaticBody3D + MeshInstance3D` с `use_in_baked_light = true` (они уже StaticBody3D с мешем).
2. Статические источники (тёплые «L», окна, будильные «r» с пульсом выключенным) перевести в `light_bake_mode = BAKED`, у «l» оставить DYNAMIC.
3. Добавить `LightmapGI` узел с `texel_scale=0.1`, `environment_mode=SCENE`, рендер → «Bake Lightmaps». Это же действие проверит light-leaks: протечь свет через меш — значит, дыра в геометрии.
4. Проверить в 3 уровнях экспозиции (см. QA.md).

## Ревизия 2 — anti-blackout слой (P0) и PBR-материалы

### Что изменилось
1. **Ambient поднят** до 0.34 (Б1) / 0.38 (1 эт.) / 0.34 (радиоэт.) — «ночного зрения»: при полностью
   разряженном фонаре читаются силуэты, проёмы и интерактивы в 2–3 м. Headless dark-QA: доля ячеек
   с освещённостью <9 м — 0% на Б1 и 1 этаже, 1.5% на радиоэтаже (worst 10.8 м — угол клетки антенны,
   компенсируется химсветильником `c (5,11)`).
2. **Аварийные плафоны 2700K** (`_make_emergency`): BoxMesh 0.34×0.14×0.12, emission `#FF9E61` ×1.6,
   OmniLight3D energy 0.55, range 5.5 м, тени выкл. Ставятся в каждую комнату без L/l/r/W
   (1 плафон на комнату, 2 при ширине >5 клеток, ±3 клетки по длинной оси).
3. **Фосфорные метки на проёмах** (`_make_phosphor`): планка 0.55×0.10 м на высоте 0.06 м,
   emission `(0.55, 0.75, 0.35) × 0.85` — маршрут виден без фонаря, свет ведёт игрока (правило 9).
4. **Bloom** (см. таблицу выше) — фосфор и аварийные LED читаются.
5. **PBR-материалы Poly Haven** (`_mat_pbr(set, tint, metal, tex_scale, use_metal_ch)`) — triplanar,
   ARM-карта: AO=R, roughness=G, metallic=B. Пол `concrete_floor_worn_001` (tint 0.55/0.56/0.58),
   стены 1 эт. `plastered_wall` (0.62/0.63/0.60), стены Б1/Б2 `concrete_wall_004` (0.52–0.56),
   дверь `rusty_metal_02` (metallic из голубого канала), рамы окон `metal_plate`. Бетон matte
   (roughness из карты), металл — с корректным metallic, без пластикового блеска.
6. **Альтернативные источники**: 6 батарей (`B`) в `battery_pickup.gd` — заряд до 100%,
   и 4 химсветильника (`c`) в `lightstick.gd` — одноразовый OmniLight 0.75/6.0 м, эмиссия
   `(0.70, 0.92, 0.42) × 1.5` (скрытая «характерная» аномалия без права на кислотность: холодный
   зелёный допускается как ЭЛТ-семейство и физический носитель — тело светстика).
7. **Реестр `light_sources`** — все lamp/маяк/окно/аварийные плафоны регистрируют позицию;
   основа для радиальных мер читаемости и для bake-разметки (правила 10–11).

### Проверка без фонаря (правило 10, dead-flashlight QA)
1. В headless-прогоне выставляется `battery=0` с первой секунды; срез проходится полностью
   (см. docs/QA.md, раздел F) — тёмных «слепых» ячеек вдоль маршрута нет.
2. В редакторе пройтись по каждому этажу с фонарём F выключенным: проёмы должны читаться
   фосфорными метками, комнаты — аварийными плафонами; если угол глухо-тёмный — добавить
   `_make_emergency` в `station_data.gd` маркером или снизить fog density этажа.
