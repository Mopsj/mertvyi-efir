# «МЁРТВЫЙ ЭФИР» (Dead Air) — vertical slice

Атмосферный хоррор от первого лица на **Godot 4.3**: заброшенная советская
радиорелейная станция «Сосна-7» зимой. Игрок — младший инженер, приехавший
восстановить питание. В станции просыпается аномалия «Тишина»
слепа, охотится на звук и имитирует голоса через громкую связь.

- 3 этажа, 4 узла связи, 3 предохранителя, техтоннель, 2 концовки.
- Управление: WASD + мышь, Shift — бег (шумит), Ctrl — присед (тихо),
  E — взаимодействие, F — фонарь, Q — бросить бутылку-приманку, Esc — пауза.
- 20–30 минут на прохождение.

## Как запустить

1. Установить [Godot 4.3](https://godotengine.org/download) (стандартная
   версия, Forward+).
2. Открыть Godot → Import → выбрать папку с этим проектом (файл
   `project.godot`).
3. Дождаться первого импорта (`sounds/*.wav` импортируются автоматически).
4. F5 — запустить.

## Структура

```
project.godot          — настройки проекта, автолоады Boot/Game/Sound
scenes/main.tscn       — точка входа (всё строится кодом)
scripts/               — game-логика (player, monster, level_builder, hud…)
scripts/station_data.gd— СГЕНЕРИРОВАН файлом tools/build_maps.py (не править руками)
sounds/                — 24 процедурных WAV (генератор tools/make_sounds.py)
tools/build_maps.py    — источник правды по картам + валидатор
docs/                  — GDD, MAP, LIGHTING, ASSETS, BUILD_PLAN, QA
ATTRIBUTION.md         — лицензии (внешних ассетов сейчас: 0)
```

## Карты

ASCII-карты и их валидация живут в `tools/build_maps.py`:

```
python3 tools/build_maps.py     # перегенерировать scripts/station_data.gd
python3 tools/make_sounds.py    # перегенерировать sounds/*.wav
```

## Документация

- docs/GDD.md — дизайн-документ (1 страница сути + детали)
- docs/MAP.md — схема станции: зоны, связи, landmark, спавны
- docs/LIGHTING.md — план освещения по каждой комнате, палитра, bake
- docs/ASSETS.md — план ассетов, запросы, лицензии, fallback
- docs/BUILD_PLAN.md — как проект устроен и собирается в Godot 4.3
- docs/QA.md — чеклисты: свет, наполнение, производительность, лицензии

## Статус проверки

- Проект прогнан в headless-режиме Godot 4.3 (официальный билд): 0 ошибок
  скриптов; полная цепочка прогресса (3 предохранителя → щиток → 4 узла →
  люк → терминал → финал) отработала автоматически; коллизии пола/окна,
  слух монстра и переходы между этажами проверены симуляцией ввода.
- В headless (dummy-рендерер) сыплются служебные сообщения
  `mesh_get_surface_count` — внутреннее сообщение заглушки рендера, в
  Forward+ этот код не участвует; на визуал и логику не влияет.
- Вся графика — процедурные материалы и примитивы (намеренный placeholder,
  путь замены на CC0-ассеты описан в docs/ASSETS.md).
- Все звуки синтезированы; замена на записанные CC0-сэмплы — drop-in
  через sound_bank.gd.
